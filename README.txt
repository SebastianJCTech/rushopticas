ROSH ÓPTICAS - WEB

Archivos:
- index.html
- style.css
- script.js
- assets/ (imágenes reales compartidas de Rosh Ópticas)

IMPORTANTE:
1. Abre script.js.
2. Busca:
   const WHATSAPP_NUMBER = "50200000000";
3. Sustituye el número por el WhatsApp real de Rosh Ópticas usando:
   código de país + número, sin "+" ni espacios.
   Ejemplo: 50255555555

Para GitHub Pages:
- Sube index.html, style.css, script.js y la carpeta assets al mismo repositorio.
- No cambies las rutas de las imágenes salvo que cambies la estructura de carpetas.

La web incluye:
- Carrusel principal automático.
- Catálogo de productos.
- Botón de WhatsApp por producto con mensaje predeterminado.
- Exámenes visuales.
- Jornadas empresariales con mensaje predeterminado.
- Promociones.
- Lentes de contacto.
- Botón flotante de WhatsApp.
- Diseño responsive.
